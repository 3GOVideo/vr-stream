# Seguridad

No publiques direcciones IP privadas, registros con información personal,
credenciales ni otros datos sensibles en GitHub Issues.

Para reportar una vulnerabilidad de manera privada, utiliza los canales de
contacto disponibles en [3govideo.com](https://www.3govideo.com/). Incluye una
descripción del problema, los pasos para reproducirlo y la plataforma afectada.
